MRIYA – WINGS OF DISCOVERY | PROTOTIPO v0.2

AGGIORNAMENTO
Questa versione sostituisce la grafica geometrica provvisoria con un ambiente illustrato di concept, una vista esterna, un hotspot ATM-01, zoom e comandi riorganizzati.

PUBBLICAZIONE SU GITHUB
1. Estrai lo ZIP.
2. Apri il repository GitHub mriya-wings-of-discovery.
3. Seleziona Add file > Upload files.
4. Carica index.html e la cartella assets completa (deve contenere mriya_interior.jpg e mriya_exterior.jpg).
5. Se GitHub chiede come gestire i file già esistenti, conferma la sostituzione di index.html.
6. Premi Commit changes. GitHub Pages aggiornerà il sito automaticamente.

Non caricare soltanto index.html: le due immagini nella cartella assets sono necessarie.

COMANDI
- Frecce oppure A/D: spostamento dell'operatore.
- E: interazione vicino ad ATM-01.
- Pulsanti: vista esterna/interna, raggiungi laboratorio, analisi, upgrade L2, zoom.

NOTA DI PROGETTO
L'ambiente illustrato è un concept artistico generato per definire la direzione visiva. Non è una ricostruzione tecnica certificata dell'An-225. Le dimensioni, i percorsi e la disposizione definitiva dovranno rispettare le caratteristiche reali già definite nel progetto.
